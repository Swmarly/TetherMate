TetherMate — Virtual Desktop over USB

1. Connect your Meta Quest with a USB 3 data cable.
2. Enable Developer Mode and USB debugging on the headset.
3. Run TetherMate.exe. No installation or administrator access is required.
4. Put on the headset and accept the USB debugging and VPN prompts.
5. Wait for TetherMate to show “Connected over USB”, then open Virtual Desktop.

TetherMate provides the network path only. Virtual Desktop and Virtual Desktop
Streamer are still required. It is independent of Meta Quest Link.
